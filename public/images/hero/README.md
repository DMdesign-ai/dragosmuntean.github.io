# Hero image

`ridge.jpg` — the Eiger north face. Supplied by Dragos from the MASSIF
template's asset repo (cdn.jsdelivr.net/gh/Sam1983Aing/aura-assets).

NOTE ON RIGHTS: this ships with a paid Aura template, so it is licensed to
template purchasers rather than freely reusable. Fine if you bought MASSIF.
If not, swap it before the site goes public — anything dropped in here as
`ridge.jpg` is picked up automatically.

If the file is absent the <img> removes itself via onerror and the generated
ridge canvas underneath shows instead, so the hero never breaks.

Replacing it:
  - horizontal, 2400px wide minimum (this one is 1587, so not retina-sharp)
  - real depth: foreground, mid range, far range
  - a clean upper area for the wordmark to sit on
  - keep it under ~400 KB after compression
