# RIMWARD

A tiny isometric action RPG set on a corporate frontier colony. One self-contained
HTML file: Three.js inlined, fully offline, no build step, no dependencies.

**Play:** open `index.html`, or visit the GitHub Pages URL of this repo.

Controls: WASD move (screen-absolute) · mouse aim · hold LMB fire ·
Shift for tactical time dilation · Tab inventory · Q medkit · R to respawn.

Built with Three.js r128. Fixed-timestep game loop, pooled lights,
rarity loot system, and a Puppeteer test harness that verified every build.
